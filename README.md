# ENAEA 新版学习平台自动连播助手 (`estudy.enaea.edu.cn`)

针对中国教育干部网络学院新版学习平台（`https://estudy.enaea.edu.cn/`）的 Tampermonkey（油猴）辅助脚本，基于平台 React 18 SPA 前端结构编写。

## 核心功能

1. **看完自动切 P（集数连播）& 自动锁定 1.25 倍速**
   - 播放页自动处理进入时的「温馨提示」弹窗并开始播放（支持默认自动静音，兼容浏览器自动播放策略）。
   - 自动选择播放器官方 `.xgplayer-playbackrate` 中的 `1.25x` 倍速选项，并在切集、切课或倍速被重置时自动重新锁定为 `1.25x`（若当前课程未开放倍速选项，则保持平台默认倍速，不强行篡改倍速）。
   - 视频结束后等待 3 秒确保平台完成学习记录上报与心跳结束，再自动切换到右侧目录中的下一集（支持跨子章节自动切集，支持文档型章节）。
   - 内置会话级已播完集数缓存，防止平台列表进度每 60 秒刷新一次导致的重复循环播放。

2. **完成当前课程自动切到下一课程**
   - 当课程全部集数播放完成后，支持两种切课策略（默认开启混合策略，可在左下角悬浮窗切换）：
     - **优先「下一个课程」+ 章末回目录切章**：自动点击顶部「下一个课程」按钮进入下一门课；若遇到「没有下一个课程」或连续遇到已完成课程，自动返回课程目录页。
     - **总是回目录按章节顺序选课**：直接返回目录页寻找下一门未完成课程。

3. **看完一章自动切章节**
   - 在 `requiredCourse` / `electiveCourses` 页面自动识别两级折叠目录（`理论教育` -> `政治理论学习` / `维护国家安全` 等）。
   - 返回目录页或初次加载时自动逐级展开折叠面板，跳过进度为 `完成` / `100%` 的课程与已学完章节，自动切入下一章节的第一门未完成课程；支持无折叠树形结构与分页列表。

4. **90% 课程评价弹窗自动跳过 & 每日上限自动停止**
   - 课程学至 90% 自动弹出「我要评价」弹窗并暂停视频时，可自动点击「暂不评价」恢复播放。
   - 检测到「已达到每日学习上限」提示时自动停止运行并提示用户。

5. **安全与防挂机验证提醒（不绕过）**
   - 遇到平台「行为验证」「请输入右侧验证码」「滑块验证」「人脸识别验证」等弹窗时，脚本会**立即自动暂停**，绝不自动点击或尝试绕过验证，同时通过悬浮窗状态变红、网页标题闪烁提示、提示音及桌面通知提醒人工处理；完成验证后自动恢复继续播放。
   - 仅使用播放器官方开放的倍速选项并保持正常页面计时心跳，不注入非法倍速或伪造后台可见性状态。

## 安装方法

1. 在 Chrome / Edge / Firefox 浏览器中安装 **Tampermonkey（篡改猴）** 扩展。
2. 点击浏览器右上角 Tampermonkey 图标 -> **添加新脚本**（或 **管理面板** -> `+` 号）。
3. 删除默认模板内容，将本仓库中的 [`enaea-auto-study.user.js`](./enaea-auto-study.user.js) 全部内容复制粘贴进去，按 `Ctrl + S` 保存。
4. 打开或刷新 `https://estudy.enaea.edu.cn/web/.../requiredCourse` 页面，左下角即会出现 **「🎓 ENAEA 连播助手」** 控制面板（支持拖拽与收起）。

## 使用建议

- **保持浏览器窗口可见**：平台存在窗口切换检测与浏览器后台标签页节能限速，挂机学习时建议将浏览器窗口保持可见或单独置顶一个小窗口，避免切换窗口导致计时不准确。
- **重置缓存**：如需重新播放某些已在当前浏览器标签页播完的集数/课程，点击悬浮窗中的 **「清除缓存」** 按钮即可。
- **手动触发**：播放页可通过悬浮窗中的 **「下一集」** / **「下一课」** 按钮手动测试或立即推进进度。
